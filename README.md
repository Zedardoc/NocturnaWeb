# Nocturna: El despertar del eclipse

Página web del proyecto Nocturna.

## Estructura
- `index.html`: contenido de la página
- `css/style.css`: estilos (paleta rojo sangre y gradientes)
- `js/main.js`: pestañas de linajes y selector de ciclos

## Uso
Abre `index.html` en tu navegador. Para publicarla en GitHub Pages, sube la carpeta al repositorio y activa Pages en Settings.

Repositorio: https://github.com/Zedardoc/Nocturna
